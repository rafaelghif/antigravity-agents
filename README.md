Built for the extreme frontiers of 2027, AAC replaces outdated prompt engineering with **Architecting Intent**, **Test-Time Compute (TTC)**, and **Recursive Self-Improvement (RSI)**. ## 🔥 Why Use AAC? (The 2027 Post-o1 Difference)

- **🔄 Mixture of Agents (MoA) Consensus Room**: Stop babysitting. AAC delegates complex tasks to a decentralized team of `planner`, `implementer`, and `reviewer` subagents. They debate asynchronously in a controlled Inbox and **MUST reach a 3/3 consensus** before touching production gates.
- **🛡️ Vericoding (Formal Verification)**: Unit tests are dead. The `reviewer` agent is mandated to generate Formal Invariants and mathematically prove your code is safe from edge-cases (e.g., `NullPointerException`) before accepting a PR.
- **🧠 DGM (Darwin Gödel Machine) Self-Mutation**: The AI actually gets smarter. If an agent fails consecutively, it utilizes its `<DGM_SELF_MUTATION_DNA>` to autonomously rewrite and evolve its own `.agents/brain/rules.md` based on empirical feedback.
- **⚡ Test-Time Compute (System-2)**: The `planner` no longer writes the first thought that comes to mind. It performs a Monte Carlo Tree Search (MCTS), simulating 3 divergent architectural trajectories and scoring them on O(N) complexity before taking action.
- **🛸 Continuous Latent Action Spaces & RSI**: Discrete autoregressive token generation is bottlenecked. AAC incorporates Mamba-3 SSM mental tracking, mapping intents to latent manifolds. If the agent lacks a tool, **Recursive Self-Improvement (RSI)** allows it to write, compile, and attach new Python scripts to its own neural structure on the fly.

## 🚀 One-Command Bootstrap

Run the reproducible installer to inject the AAC Post-o1 Harness into your existing repository.

### Linux / macOS / WSL
```bash
curl -fsSL https://raw.githubusercontent.com/rafaelghif/antigravity-agents/v4.4.42/install.sh | bash
```

### Windows PowerShell
```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; iwr -useb https://raw.githubusercontent.com/rafaelghif/antigravity-agents/v4.4.42/install.ps1 | iex
```

> **Note**: Don't forget to configure your databases! AAC automatically hooks up your workspace to Postgres, MySQL, or MSSQL via the **Model Context Protocol (MCP)** defined in `.agents/config.json`.
