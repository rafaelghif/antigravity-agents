---
name: security
description: Use for credentials, authentication, MCP, installers, CI, permissions, dependencies, or security-sensitive changes.
---

- Keep secrets in environment variables or Antigravity auth providers.
- Review command, file, URL, MCP, and network permissions.
- Reject mutable downloads and unpinned action/container references.
- Scan changed files and logs for secret leakage.
- Report severity, evidence, blast radius, and minimal remediation.
